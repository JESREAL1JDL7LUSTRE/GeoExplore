# Ethics and Impact – GeoExplore

## Stakeholders
- Users (students, researchers, general public)
- Developers
- API providers (REST Countries)
- Educators (if used in academic setting)

## Potential Ethical Risks

### 1. Misinformation
- API data may be outdated or incomplete

**Mitigation:**
- Display source (REST Countries API)
- Indicate that data may change

### 2. Over-reliance on External API
- System depends entirely on third-party data

**Mitigation:**
- Inform users about dependency
- Handle API errors gracefully

### 3. Accessibility Issues
- UI may not be fully accessible to all users

**Mitigation:**
- Use readable fonts and proper contrast
- Follow basic accessibility practices

---

## Impact

### Positive Impact
- Easy access to country information
- Useful for learning and research
- Saves time compared to manual searching

### Negative Impact
- Dependency on internet connection
- Limited offline capability

---

## Conclusion
GeoExplore has minimal ethical risk and provides more benefits than harm when used responsibly.
