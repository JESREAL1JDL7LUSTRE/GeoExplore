# Cost-Benefit Analysis – GeoExplore

## 1. Development Cost

Estimated development effort:

- Total hours: 60 hours  
- Hourly rate: ₱150/hour  

**Development Cost = Hours × Rate**  
= 60 × 150  
= **₱9,000**

---

## 2. Operational Cost

Estimated monthly costs:

- Hosting (Vercel): ₱0 (free tier)
- Maintenance effort: 5 hours/month × ₱150/hour = ₱750

**Monthly Operational Cost = ₱750**

---

## 3. Benefits

### Tangible Benefits
- Faster access to country data using API
- No need for manual data collection
- Reduced development complexity (no backend/database)
- Lower infrastructure cost

### Intangible Benefits
- Improved user experience (modern UI, responsive design)
- Better workflow efficiency
- Learning experience in API integration and frontend development
- Scalable system for future features

---

## 4. ROI Calculation

Assume the system saves:

- 10 hours/month of manual work  
- Value per hour = ₱150  

**Monthly Value = 10 × 150 = ₱1,500**

**Monthly Net Gain = Value – Cost**  
= 1,500 – 750 = **₱750**

**ROI = (Net Gain / Cost) × 100**  
= (750 / 750) × 100  
= **100% ROI**

---

## 5. Case Study Scenario

If this system is used by **50 users**, the impact is:

- Each user saves time accessing country information
- Total time savings increase significantly
- Improves efficiency in academic and research tasks
- Reduces repetitive manual searching

---

## 6. Recommendation

**Proceed with the system.**

### Justification:
- Low development cost (₱9,000)
- Minimal operational cost (₱750/month)
- High ROI (100%)
- Easy to maintain and scale
- Provides both functional and educational value

The system is cost-effective, efficient, and suitable for real-world and academic use.
