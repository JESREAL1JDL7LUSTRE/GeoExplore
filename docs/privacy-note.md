# Privacy Note – GeoExplore

## Data Collection
GeoExplore does not collect or store personal user data.

## API Usage
The system fetches public data from the REST Countries API.

## Purpose of Data
- To display country information such as name, population, and region
- To support search and filtering features

## Data Storage
- No user data is stored
- No database is used

## User Rights
- Users are not required to log in
- No personal data is tracked or retained

## Conclusion
GeoExplore is a stateless system and does not pose privacy risks to users.
