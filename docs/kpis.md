# KPIs – GeoExplore Project

## 1. API Response Time
Measures how long the app takes to fetch data from the REST Countries API.
Target: ≤ 500ms

## 2. Application Availability
Measures how often the app is accessible and running.
Target: ≥ 99%

## 3. Defect Rate
Measures the number of bugs found per sprint.
Target: ≤ 2 bugs per sprint

## 4. Deployment Frequency
Measures how often updates are deployed.
Target: 2–3 deployments per week

## 5. Lead Time for Changes
Measures how long it takes from code commit to deployment.
Target: ≤ 2 days
